On-Orbit Autonomous Cargo Exchange Module

Cargo Exchange Module for Autonomous Cargo Transfer in Space.

← Back to projects

Overview

Advanced prototyping of a cargo exchange module (CEM) for on orbit autonomous cargo transfer. Designed, printed, and assembled circuit boards to integrate onto a large-scale 4-foot functional cargo transfer model.

Technical challenge

Develop a PCB to consolidate all electronics on the CEM. Used schematic files of all electrical components to get exact dimensions of each board. Transferred dimensions into new schematic file so each board could be inserted directly onto the PCB Components to consider: Artemis ATP Arduino DUE OpenLog SD Logger 3 Motor Drivers 3 Current Sensors 3 Temperature Sensors 2 Hall Effect Sensors

Board design

Created custom PCB shape to integrate with the contraints of the CEM prototype. Successfully routed all component traces and vias. Manufactured 2 identical PCBs integrating all components. Soldered and tested all components to ensure functionality.

Integration & Testing

Designed and 3D printed custom pieces to seamlessly fit the PCB into the CEM prototype.
